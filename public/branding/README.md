# RLCA brand assets

`rlca-logo-transparent.png` is the authoritative Rocket League Competitive
Association league logo. It is the approved transparent 1254 × 1254 PNG and
must remain free of baked-in backgrounds, frames, or CSS recreation.

Website backgrounds are implemented separately in `src/app/globals.css`.
Tier artwork under `branding/tiers/` is a separate official asset system and
must not be replaced by the league logo.
